# 国内车队报警原型评审结论

- 规则边界以商户为基准，同一商户内一辆车最终只取一套报警规则。
- 机构配置必须提供下级机构范围和覆盖已有高优先级配置两个开关，解决先单车配置、后机构统一配置时无法覆盖的问题。
- 列表采用单车维度，一车一行，展示各报警项合并后的最终生效状态；多选车辆规则不一致时红色提示但允许保存为相同的车辆级配置。
- 列表页避免复杂 SQL 实时联查，按单车在内存中匹配继承关系；建议分页大小为 50。
- 配置团队负责规则存储和同步，平台侧负责实时流计算；同车同类型报警在一小时内去重，避免重复推送。
- APP 与 Web 遵循同一权限和生效逻辑；能源类型 Tab 按车辆动态显示，非新能源车保存时提示可能不生效。

## 待确认

- 同级机构“最后设置”的确定性排序和并发写入处理。
- 配置同步的确认、重试、幂等和延迟指标。
- 一小时去重的报警类型全集及跨平台一致性。
- 增程车等混合车型的兼容时间表。
