# 海外安全整改会议结论

- 依据：[[overseas-telematics/sources/2026-09-09-inbox-海外安全整改会议|2026-09-09 海外安全整改会议]]
- 整理日期：2026-09-10
- 范围：越南、菲律宾、俄罗斯、沙特等海外项目的会议讨论；未提供完成或验收证据。

## 会议决定与提出的需求

| 事项 | 会议口径 | 状态与边界 |
| --- | --- | --- |
| 隐私协议 | 记录点击同意日志，更新协议文本 | 文本需客户确认 |
| 数据库存储 | 可采用华为云磁盘透明加密，应用层无需改动，由运维实施 | 会议候选实施方案；无国密要求是会议陈述 |
| OBS 存储 | 开启加密后的新数据自动加密，历史数据需迁移或重写 | 会议技术判断；历史处理工作量待大数据团队评估 |
| 跨境系统传输 | 会议称已有 SSL/TLS，提出增加敏感数据应用层加密与消息签名 | 未提供具体方案或完成证据 |
| 展示脱敏 | VIN、手机号默认打星，支持点击或悬停查看明文 | 按客户需求执行前端脱敏，暂不引入复杂后端权限分级；安全争议未消除 |
| 数据导出 | 统一限制行数；敏感文件加密并生成独立密码；添加用户名水印 | 1 万行仅是示例，功能阈值由产品最终确定；密码交付和权限分离细节未说明 |
| 操作日志 | 登录、新增、修改、删除、导出等操作至少留存 12 个月 | 会议需求；暂不需记录详细数据内容变更 |
| 网络行为 | 海外 SIM 终端在国内段连接海外平台时，记录源/目的 IP、端口、流量等 | 会议称适用于所有海外区域；采集落点未说明 |

## 建议方案

- 运营平台与车队管理等被视为同一系统的内部调用，不强制 HTTPS 双向认证；跨系统调用建议采用双向认证或 API 密钥。此口径不等于内部调用无需认证。
- 对沙特等地区提出的永久保存要求，建议分级存储、固定期限及清除机制；5 年或 10 年是举例，未形成最终保留期限。

## 待确认与分工

- 客户侧：隐私协议文本、DLP 和外发控制的具体技术要求。
- 产品侧：各导出功能的最终行数阈值。
- 大数据团队：OBS 历史数据迁移或重写的工作量。
- 运维侧：数据库磁盘透明加密实施；记录未给负责人、排期和完成状态。
- 待补方案：应用层加密与签名、导出密码交付及权限分离、网络行为采集落点、最终保留期限与清除规则。原文未给明确责任人或截止日期。
